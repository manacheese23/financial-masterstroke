# 💰 Financial Masterstroke

A collection of personal finance tools and projects built to explore financial management, programming, and data analysis.

## 📌 About

**Financial Masterstroke** is a personal finance project focused on making financial tracking simpler and more accessible through software.

The repository currently features **FinTrack**, a Python-based desktop application that allows users to manage transactions, monitor income and expenses, and visualise their financial activity.

## 🚀 Featured Project: FinTrack

FinTrack is a desktop-based personal finance manager developed using Python.

### ✨ Features

- **Transaction Management** — Record and manage income and expenses.
- **Expense Tracking** — Categorise and monitor spending.
- **Financial Overview** — Review income, expenses, and balances.
- **Data Visualisation** — Understand financial activity through charts.
- **CSV Storage** — Store transaction records in an accessible CSV file.
- **Desktop Interface** — Interactive graphical interface built with Tkinter.

### 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Core programming language |
| Tkinter | Graphical user interface |
| CSV | Transaction data storage |
| Matplotlib | Financial charts and visualisation |

## ▶️ Getting Started

### Run from source

1. Install Python 3.
2. Install the required dependencies.
3. Clone this repository:

```bash
git clone https://github.com/manacheese23/financial-masterstroke.git
```

4. Open the project directory.
5. Run:

```bash
python finance_manager.py
```
